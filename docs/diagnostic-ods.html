1 Le script déployé contient-il le code ODS ?

Ouvre l'URL dans un nouvel onglet et lis ce qui s'affiche. C'est le test le plus fiable : il ne dépend ni du CORS ni du jeton.

Ce que tu voisConclusion
{"ok":true,"action":"ping",…}✅ Script correctement déployé — passe à l'étape 2.
Fonction de script introuvable : doGet❌ Déploiement antérieur au collage du code → Déployer > Gérer les déploiements > ✏️ > Version : Nouvelle version > Déployer.

État actuel constaté le 07/09/2026 : la réponse est « Fonction de script introuvable : doGet ». Il faut redéployer en nouvelle version.

2 Le POST est-il accepté ? (jeton + onglets)

Envoie un ping en POST. Si le navigateur bloque la lecture (CORS), l'onglet s'affichera « envoyé, réponse illisible » : c'est normal depuis un fichier local, la vérification se fait alors à l'étape 3.

3 Une fiche de test arrive-t-elle dans le tableur ?

Envoie une ligne ID_OBSERVATION = DIAG-… (espèce : Bouleau verruqueux, stade F1). Ouvre ensuite le tableur : la ligne doit apparaître dans ODS_Releves. Pense à la supprimer après le test.

4 L'onglet ODS_Export se génère-t-il ?

Reconstruit l'onglet d'export au format obs-saisons.fr à partir des relevés. Une ligne de test produira une ligne F1 dans ODS_Export.
